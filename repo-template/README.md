# 👋 Bienvenido, equipo

Este es **el repo de tu equipo para la materia computacion emergente** para el trimestre. Aquí van a subir, a lo largo de todo el
curso, todas las tareas y actividades que se les asignen: cada entrega es un commit y push
a este mismo repo, no un repo nuevo por tarea.

## ¿Qué hay acá?

- **`preguntas.json`**: donde va el contenido de la tarea (respuestas del equipo). El
  formato exacto y los criterios están en la guía de la tarea correspondiente, en el repo
  central del curso.
- **`tests/`**: validadores que corren localmente antes de subir nada.
- **`requirements.txt`**: dependencias para correr los tests.

## Cómo trabajar

1. Clona este repo.
2. Instala dependencias: `pip install -r requirements.txt`
3. Edita `preguntas.json` con las respuestas de tu equipo.
4. Corre los tests localmente antes de subir: `pytest`
5. Si los tests pasan, commit y push.

Cada commit queda con autor y timestamp — es la evidencia de quién hizo qué y cuándo.

## El delegado del equipo

Uno de ustedes fue invitado directamente como colaborador (permiso de escritura) para
poder repartir el acceso: **el profesor no tiene los usernames de todo el curso**, así que
invita solo a un delegado por equipo, y es el delegado quien agrega al resto desde:

`Settings > Collaborators and teams > Add people` (en este mismo repo)

Si todavía no tienes acceso, pídele a tu delegado que te agregue ahí.

## Importante

- El repo es **público**: cualquiera puede ver el contenido, pero solo quienes fueron
  agregados como colaboradores pueden subir cambios.
- No copien respuestas de otro equipo: hay un chequeo automático de similitud entre
  equipos y queda todo con marca de tiempo por commit.
